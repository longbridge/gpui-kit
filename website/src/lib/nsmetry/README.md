# nsmetry (vendored)

A copy of the `nsmetry` JavaScript client (MIT) from
[huacnlee/nsmetry](https://github.com/huacnlee/nsmetry/tree/b7bbd71/sdk/js/src),
commit `b7bbd71`. The package is not on npm yet; replace this folder with the
`nsmetry` dependency once it is published.

`core.ts` and `index.ts` are unchanged. To update, copy both files from
`sdk/js/src` in that repository.
